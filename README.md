# Tool

Các công cụ hỗ trợ nghiệp vụ BHXH.

## Quanlychiphi – Kiểm tra Phụ lục 01 (chi phí chi trả, quản lý người hưởng 2026)

- [`Quanlychiphi/KiemTra_PL01.html`](Quanlychiphi/KiemTra_PL01.html): công cụ chạy offline trong trình duyệt. Chọn file Excel kê khai của BHXH cơ sở (mẫu PL01, sheet `Bieu_xa`), công cụ đối chiếu với Bảng đơn giá chung PL02 và báo các khoản sai hoặc cần thuyết minh theo từng xã/khoản, kèm số tiền kê khai thừa ước tính. Có xuất kết quả ra Excel. File được đọc ngay trên máy, không gửi đi đâu.
- [`Quanlychiphi/Guide/`](Quanlychiphi/Guide/): file hướng dẫn đơn giá PL02 (bản 19/11/2026) và [README](Quanlychiphi/Guide/README.md) mô tả các trường.
- `Quanlychiphi/Lâm Thao 23.11.xlsx`: file kê khai mẫu dùng để thử công cụ.

**Cách dùng:** tải `KiemTra_PL01.html` về máy, mở bằng trình duyệt (Chrome, Edge…), chọn hoặc kéo thả file Excel kê khai vào.
